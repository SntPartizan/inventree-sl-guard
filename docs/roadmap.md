# Roadmap

These are goals, not shipped capabilities:

- [ ] Full English / Russian interface localization (Lingui on frontend, Django gettext on backend where applicable)
- [ ] InvenTree 1.6.x compatibility matrix in CI and integration tests against PostgreSQL
- [ ] Replace serializer monkey patch with a supported upstream extension point
- [ ] Improve error messages surfaced in the standard InvenTree mobile / barcode UI upstream
- [ ] Audit delete operations and MPTT/bulk update bypasses
- [ ] Improve large-instance pagination, audit log and performance diagnostics
- [ ] Publish a reviewed release to PyPI and request inclusion in the InvenTree community plugin list
