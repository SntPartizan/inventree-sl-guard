# SL Guard — защита складских локаций InvenTree

**Версия 0.3.0 beta. Проверена на InvenTree 1.6.1. Не является официальным компонентом InvenTree.**

Плагин предотвращает случайное перемещение стационарных локаций. Администратор выбирает защищённые типы (например, «Стеллаж», «Полка»), после чего перемещение этих локаций или их родителей с защищёнными потомками доступно только суперпользователю либо разрешённым группам — с учётом штатных прав InvenTree.

## Возможности

- Выбор защищённых `StockLocationType` по **ID**.
- Первое назначение защищённого типа по стандартным правам пользователя.
- Запрет изменения `parent` и снятия/смены уже защищённого типа для неуполномоченных пользователей.
- Защита при косвенном перемещении (перемещение предка, содержащего защищённую SL).
- Массовая установка типов: полные пути, ID, чекбоксы, поиск с включаемыми полями и Regex, предварительный просмотр, транзакционное применение.
- Пункт навигации **SL Guard** и компактный виджет **SL Guard** на дашборде с одинаковой иконкой щита. Оба элемента включаются независимо.
- Установка без изменения файлов ядра на диске.

## Установка

Если установлена прежняя версия Fixed Location Guard, сначала выполните [инструкцию перехода](docs/migrate-from-old-plugin.md), чтобы не активировать два плагина одновременно.

1. Создайте резервную копию БД InvenTree, сначала тестируйте на локальной копии.
2. Установите `.whl` в **то же окружение Python**, где работает InvenTree:

   ```bash
   /path/to/inventree/venv/bin/python -m pip install --no-deps --upgrade ./inventree_sl_guard-0.3.0-py3-none-any.whl
   ```

3. Проверьте настройку `plugins_enabled: true`, перезапустите веб-сервер и фоновый worker (если используется).
4. В Settings → Plugins активируйте SL Guard. Включите интерфейс и URLs плагинов в глобальных настройках InvenTree при необходимости.
5. Из каталога `manage.py` с конфигурацией **того же** InvenTree запустите `python manage.py collectplugins`. Обновите браузер через Ctrl+F5.
6. Откройте `/web/plugin/sl-guard/manage`.
7. В **SL Guard → Protection settings → Quick access** включайте/отключайте показ пункта меню и виджета. Сам виджет нужно добавить через штатную настройку дашборда InvenTree.

Название **SL Guard** одинаковое для русского и английского интерфейса. **Внутренние идентификаторы теперь тоже новые:** `SLGuard`, `sl-guard`, `sl_guard`, `inventree-sl-guard`. Это новая установка, а не обновление старого пакета. Прежние настройки защищённых типов и групп автоматически не переносятся. См. [инструкцию перехода](docs/migrate-from-old-plugin.md). Для GitHub — `inventree-sl-guard`.

## Порядок работы

Сначала создайте тип штатными средствами InvenTree. Затем найдите нужные локации в панели, отметьте галочками, выберите тип и проверьте предварительный список **полных путей и ID**. Примените назначение. После этого отметьте тип как защищённый и укажите группы, которым разрешено управление.

Поиск проверяет только **название** по умолчанию. Поиск по полному пути включается отдельным переключателем: если его включить, запрос «Стеллаж» также найдёт все коробки, находящиеся на стеллажах. Regex `Стеллаж|Полка` означает ИЛИ, `^(Стеллаж|Полка)` ищет названия с этих слов.

**Важно:** при ошибке `timeout` нельзя считать, что транзакция отменена. Перезагрузите таблицу и проверьте реальные типы перед повторным применением.

## Проверка прав

| Операция | Обычный пользователь с правом редактирования SL | Superuser / разрешённая группа |
| --- | --- | --- |
| Первичное назначение защищённого типа | Да | Да |
| Снятие / смена уже защищённого типа | Нет | Да |
| Перемещение защищённой SL или её родителя | Нет | Да |
| Переименование / описание | Да | Да |

Действуют дополнительные штатные ограничения InvenTree (роли, владение локацией).

## Ограничения

Этот плагин **не меняет файлы ядра InvenTree**, но использует monkey patch `LocationSerializer.validate()` для штатного перемещения под администратором. Поэтому после обновлений InvenTree требуется тестировать совместимость. Обходными путями остаются прямой SQL, `QuerySet.update()`, отдельные массовые операции дерева и удаление защищённых типов. Для пользовательского сообщения на экране сканирования отдельный *необязательный* скрипт может менять исходник UI InvenTree — не применяйте его без самостоятельного решения и пересборки интерфейса.

Тестирование: `python -m pytest -q tests` и `node --test tests/js/*.test.mjs`. Подробнее: [матрица проверок](docs/test-matrix.md).

Плагин развивается как независимый open-source проект под лицензией MIT. Панель управления переведена на русский и английский; выбор языка происходит автоматически.


## Локализация

В версии **0.3.0** интерфейс панели доступен на английском и русском языке. Язык панели определяется настройкой языка интерфейса InvenTree (`context.locale`), английский используется по умолчанию. Ошибки API переводятся по активному языку Django. Статические поля настроек плагина (названия параметров) пока представлены на английском. См. [подробности](docs/localization.md).
